Share over Internet

Share the web remote with viewers outside your local network using a free Cloudflare Quick Tunnel (no account required).

Security: Anyone with the tunnel link can use the web remote until you turn this off or restart the app. Treat the link like a password. Your controller IP allowlist does not apply to traffic through this tunnel (connections arrive from localhost). You can add a numeric PIN below so the web remote asks for it before loading over the tunnel.

Tunnel traffic hits this machine as localhost, so it does not match "LAN IPs only". Use "Tunnel and local network" to PIN-protect both the share link and phones or laptops on your Wi‑Fi.
4–12 digits. Browsers must unlock once (cookie) when a PIN is set and the request matches the option above.
Points the tunnel at your Web UI port. Run yarn download:cloudflared once before testing or building.
The URL changes each time the app starts. Requires internet access.

Primary / Backup

Configure this instance as primary (controls backups) or backup (follows primary)

Port used to communicate with backup machines (default: 9595, same as API port)

PerfectCue Network Extender

Accept slide advance/back commands from DSAN PerfectCue network extenders over TCP. Add one port per extender (or group).

Default port is 8899. Add one entry per network extender or subnet if they connect on different ports.

Controller Allowlist

Restrict which IP addresses can control this app via the Web UI and HTTP API. If left empty, any device on your network can control the app.

Tip: Use the IPs shown above in "Network Access". You can also allow a subnet using CIDR (e.g. 192.168.1.0/24). Localhost (127.0.0.1) is always allowed.
